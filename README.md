## Overview

T.O.O.L. (Transform Object Off-Lot) is a The Sims 4 mod that lifts the game's placement restrictions, allowing players to position furniture and objects outside lot boundaries, underground, in mid-air, with unrestricted rotation angles, and with fine-grained position control measured in centimeters. It is an essential tool for builders creating elaborate outdoor scenes, underground spaces, and architectural details that vanilla placement prevents.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **T.O.O.L.** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Off-Lot Placement** | Place objects outside lot boundaries for expanded build creativity |
| **Precise Positioning** | Fine-grained XYZ position control measured in centimeter increments |
| **Free Rotation** | Place objects at any rotation angle, not just the standard 45° snaps |
| **Underground Objects** | Lower objects below terrain level for basements and buried details |
